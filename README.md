Development started somewhere around **December 2023** (Rust 1.74+) and has been going pretty well to this day since then.<br>
This includes a language rewrite and a more reliable features than previous revision while being efficient and performant as possible!

Notable features;-
- FSMP infrastructure with the HTTP backend being hosted separately
- gRPC service support (for above)
- (Auto)moderation
- Autoresponders
- Legacy prefix commands for basic operations

> [!IMPORTANT]
Starting with version 4.4.3, the development has slowed down and moved to another place with future development being done privately. As a result, this repository will be archived and what you see is the current state and there's no plans to bring this repository up to date, you can blame GitHub for all the work they been doing lately to infest the site with AI tools and having unneeded features everywhere.
